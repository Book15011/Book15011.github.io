# Can You Beat My Poker AI?

A heads-up No-Limit Texas Hold'em game against an AI trained by self-play, which solves the turn and river live in your browser. Virtual chips only.

**[Play it](https://book15011.github.io/quant.html#poker)** · **[How it works](https://book15011.github.io/poker/how-it-works.html)**

This folder is the published copy of the game that the website serves. The source code, tests, training pipeline, research notes and benchmark results are in **[Book15011/Poker_bot_web](https://github.com/Book15011/Poker_bot_web)**, which updates this folder with `scripts/publish_site.py`. Make changes there, not here.
